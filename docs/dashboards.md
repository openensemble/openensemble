# Display dashboards

Create dedicated tablet and browser views with Home Assistant controls,
calendar, email, node status, and custom-skill widgets. Each profile can keep
up to 32 dashboards with stable addresses and separate portrait/landscape layouts.

![An OpenEnsemble display dashboard]({{ site.baseurl }}/assets/display-dashboard.png)

The [complete dashboard guide]({{ site.baseurl }}/guide/dashboards/) covers
creating a display, editing layouts, adding cards, saving and recovering changes,
and opening it on a tablet. These instructions also ship in the in-app Guide.

Displays require an OE login and use the signed-in profile's permissions.
Use a dedicated profile with limited access for unattended screens.
