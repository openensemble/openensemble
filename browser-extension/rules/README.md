# OE ad rules

`ads.json` is a small, locally packaged set of conservative network rules for
well-known advertising platforms. Rules block only third-party subresources;
they never block a top-level navigation. The extension does not download a
remote filter list or report matches to OE.

This list is maintained as part of OpenEnsemble under the repository license.
Site-specific elements that the list misses can be taught locally with the
**Block this ad with OE** context-menu action.
