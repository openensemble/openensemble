# Find work and review what needs attention

## Search your work

Press **Ctrl+K** (Windows/Linux) or **Cmd+K** (Mac), or open Search from the menu.
Search covers your original conversations, saved chats, project chats, saved
project results, profile-file names, and supported text-file contents. Use the
category selector to narrow the results.

A conversation result opens the exact saved message with nearby context. A saved
result opens its content and, when available, a link to the source message. A file
result opens the original file viewer. Search only includes your account's work.

Large profiles show a coverage notice when the bounded search reaches its limits.
Try a more specific phrase or a category. File-content search does not run OCR or
transcribe media.

## Needs attention

Open **Needs attention** from the sidebar or mobile menu. The badge counts work
that needs a decision: pending approvals, failed schedules and monitors,
disconnected nodes or automatic network shares, uncertain email sends, paused
jobs, and budget pauses. Administrators also see failed backup checks.

Pending suggestions are reviewed here. Read the proposed change, its reason,
and its preview, then choose **Accept**, **Dismiss**, **Snooze 7d**, or **Don't
propose again**. Bulk actions apply only to the suggestions shown. A proposal
notice in chat opens its item here. **Learn** keeps learning settings, saved
knowledge, and accepted history; it no longer has a pending-suggestions inbox.

For other items, filter by category and use the action to open the relevant conversation,
task, connection settings, or recovery screen. Opening the queue does not retry a
task, resend email, reconnect a share, or increase an allowance. Those actions
stay in their existing review flows.

The queue refreshes while open and after relevant activity. If a source cannot be
checked, the status names that source; an empty partial result is not an all-clear.
Very large queues display the first 200 items. Resolve them and refresh to see
more.
